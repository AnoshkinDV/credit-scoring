# Credit Scoring EDA Project

Анализ данных по кредитному скорингу с целью выявления факторов, влияющих на вероятность дефолта. Проект направлен на определение клиентских сегментов с повышенным риском и предоставление аналитических выводов для поддержки решений в сфере финансов.

## Описание проекта

**Цель:**  
Определить ключевые факторы, влияющие на невозврат кредитов, и выделить группы клиентов с повышенной вероятностью дефолта.

**Датасет:**  
- 307 511 строк  
- 122 признака  
- После очистки — 34 ключевых признака

## Этапы работы

- Исследование данных: первичный анализ и отбор релевантных признаков  
- Очистка данных: обработка пропусков, удаление неинформативных столбцов  
- Анализ выбросов: выявление аномальных значений в доходе, сумме кредита, размере семьи  
- Статистический анализ: расчет перцентилей, медиан, стандартных отклонений  
- Фичеринжиниринг: преобразование признаков (например, перевод `DAYS_BIRTH` в возраст)

## Ключевые результаты

- Удалено более 70% признаков с большим количеством пропусков или низкой значимостью  
- Проведены расчеты по 95-му и 99-му перцентилям для обоснования обработки выбросов  
- Сформирована основа для построения моделей и клиентской сегментации

## Используемые технологии

- **Язык программирования:** Python  
- **Библиотеки:** pandas, numpy, seaborn, matplotlib  
- **Методы:** EDA, статистический анализ, очистка и преобразование данных

## Зачем это нужно

Результаты анализа позволяют:
- Снижать риски невозврата кредитов  
- Повышать точность и обоснованность кредитных решений  
- Оптимизировать процессы кредитования на основе данных
