📊 Credit Scoring EDA Project
Анализ данных по кредитному скорингу с целью выявления факторов, влияющих на вероятность дефолта. Проект помогает определить сегменты клиентов с повышенным риском и предоставляет ценные аналитические выводы для финансовых организаций.

🧩 Описание проекта
Цель:
Определить ключевые факторы, влияющие на невозврат кредитов, и выделить группы клиентов с повышенной вероятностью дефолта.

Датасет:

307 511 строк

122 исходных признака

После очистки — 34 ключевых признака

🔧 Этапы работы
📌 Исследование данных: предварительный анализ и отбор значимых признаков

🧹 Очистка данных: обработка пропусков, удаление неинформативных столбцов

📈 Анализ выбросов: выявление аномалий в доходе, сумме кредита, размере семьи

📊 Статистика: расчет перцентилей, медиан, стандартных отклонений

🛠️ Фичеринжиниринг: преобразование признаков, например, перевод DAYS_BIRTH в возраст

💡 Ключевые результаты
🔻 Сокращено более 70% исходных признаков за счёт фильтрации по качеству данных

📊 Предоставлены метрики (95-й/99-й перцентили) для обоснования работы с пропущенными и выбросами

👥 Подготовлена база для сегментации клиентов и построения моделей

🛠 Используемые технологии
Язык: Python

Библиотеки: pandas, numpy, seaborn, matplotlib

Методы: EDA, статистика, очистка и трансформация данных

🚀 Следующие шаги
Построение моделей прогнозирования дефолта (логистическая регрессия, случайный лес и др.)

Более глубокая сегментация клиентов (по занятости, доходу, региону)

📌 Зачем это нужно
Результаты анализа помогут:

📉 Снизить кредитные риски

🧠 Принимать решения на основе данных

💰 Повысить эффективность и прибыльность кредитования
